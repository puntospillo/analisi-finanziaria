# Analisi Finanziaria

Dashboard sul rischio del mercato azionario americano (S&P 500): indice di rischio 0–100, quota in azioni suggerita (allocazione adattiva e algoritmo 3.0), report del mese, mercati esteri, prova sul passato e valutazione con fonti esterne.

**Sito:** https://puntospillo.github.io/analisi-finanziaria/

## Come si aggiorna
- I dati e la valutazione si aggiornano **solo su richiesta**: vengono elaborati con Claude e pubblicati in questo repository. Non ci sono aggiornamenti programmati né chiavi API nella pagina.
- `ifi_data.json` = dati e indice calcolati; `valutazione.json` = ultima valutazione; `archivio/` = report mensili passati e opportunità ad alto rischio per data; `code/` = script di calcolo.
- `tools/make_github.py` trasforma la pagina originale nella versione statica di questo sito.

## Avvertenza
Indicazioni generali basate su dati di mercato e su regole studiate sul passato: non sono consulenza finanziaria personalizzata. Le idee e le opportunità sono spunti da approfondire.
